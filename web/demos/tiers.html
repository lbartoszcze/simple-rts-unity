🎬 Procedural fantasy characters — generated, not imported

Every vertex of every model below is built at runtime in web/art/anatomy.js from THREE.js primitives (LatheGeometry, SphereGeometry, CylinderGeometry, etc.) at high segment counts. Polygon target: ~6,000 triangles per character, matching the reference Unity Low-Poly Axe Warrior. Live polygon counter on each cell.
